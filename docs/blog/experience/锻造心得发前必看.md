## 相关Markdown语法

### 通用语法

#### 段落和换行

一个段落是由一个以上相连接的行句组成，而一个以上的空行则会切分出不同的段落。

如果需要换行请在两个段落间添加空行，或在上一个段落的结尾添加==两个空格==。

#### 标题

文字前加`#`和**一个空格**为标题，标题级别由`#`数量决定

```md
# This is an H1

## This is an H2
```

在行首插入 1 到 6 个 `#` ，对应到标题 1 到 6 阶，例如:

- H1: `# Header 1`
- H2: `## Header 2`
- H3: `### Header 3`
- H4: `#### Header 4`
- H5: `##### Header 5`
- H6: `###### Header 6`

#### 引言

引言是在在每行的最前面加上 `>` :

```md
> This is a blockquote with two paragraphs. Lorem ipsum dolor sit amet,
> consectetuer adipiscing elit. Aliquam hendrerit mi posuere lectus.
> Vestibulum enim wisi, viverra nec, fringilla in, laoreet vitae, risus.
>
> Donec sit amet nisl. Aliquam semper ipsum sit amet velit. Suspendisse
> id sem consectetuer libero luctus adipiscing.
```

渲染为如下效果：
> Vestibulum enim wisi, viverra nec, fringilla in, laoreet vitae, risus.
>
> Donec sit amet nisl. Aliquam semper ipsum sit amet velit. Suspendisse
> id sem consectetuer libero luctus adipiscing.

要是两行引言分开请在其间插入空行 :

```md
> Vestibulum enim wisi, viverra nec, fringilla in, laoreet vitae, risus.

> Donec sit amet nisl. Aliquam semper ipsum sit amet velit. Suspendisse
```

渲染效果如下：
> Vestibulum enim wisi, viverra nec, fringilla in, laoreet vitae, risus.

> Donec sit amet nisl. Aliquam semper ipsum sit amet velit. Suspendisse

块引言可以有阶层，只要根据层数加上不同数量的 `>` :

```md
> This is the first level of quoting.
> > This is nested blockquote.

> Back to the first level.
```

渲染效果如下：

> This is the first level of quoting.
> > This is nested blockquote.
>
> Back to the first level.

引言的块内也可以使用其他的 Markdown 语法，包括标题、列表、代码块等

#### 列表

有序列表和无序列表。

无序列表:

```md
- Red
- Green
- Blue
```

有序列表则使用数字接着一个英文句点:

```md
1.  Bird
2.  McHale
3.  Parish
```

列表也可以通过<kbd>Tab</kbd>进行层级划分。

#### 分隔线

三个连续的减号为分割线

::: info
本百科二级标题上方自动有一条分隔线
:::

#### 链接

链接的文字用 `[方括号]` 来标记，链接地址用`(圆括号)`标记。

==方括号内的文字何以自定义==

```html
[百度](http://www.baidu.com)
行内链接：
[列表](#列表)
```

[百度](http://www.baidu.com)和[列表](#列表)

#### 加粗

```md
**double asterisks** (建议)

**double underscores** (建议)
```

#### 代码

如果要标记一小段行内代码，你可以用反引号把它包起来 (`` ` ``)

你可以用它来表示游戏中某些特殊名称或者物品

!!代码标记里为什么一定要是代码呢!!

#### 图片

[链接](#链接)格式前加一个`!`地址为图片路径  
`docs`文件夹下为根目录，请将文章所用图片新建一个文件并放进`blog`/`image`文件夹  
==使用发布页面会自动放进正确的位置直接引用就好=={.warning}

#### 其他文本样式

- 删除:`~~delete~~`
- 段落: 段落之间空一行
- 换行符: 一行结束时输入两个空格

#### 表格

请尽量不要使用表格!!不是很好用!!

``` md
|     居中      |         右对齐 | 左对齐         |
| :-----------: | -------------: | :------------- |
| 居中使用`:-:` | 右对齐使用`-:` | 左对齐使用`:-` |
|       b       |      aaaaaaaaa | aaaa           |
|       c       |           aaaa | a              |
```

|     居中      |         右对齐 | 左对齐         |
| :-----------: | -------------: | :------------- |
| 居中使用`:-:` | 右对齐使用`-:` | 左对齐使用`:-` |
|       b       |      aaaaaaaaa | aaaa           |
|       c       |           aaaa | a              |

### 拓展语法

#### 文字标红

``` html
需要标红的<span class="important">文字部分</span>
```

需要标红的<span class="important">文字部分</span>

!!如果你会HTML那你一定看的懂这是什么，看不懂仿照就好了!!

#### 标记

``` md
==标记内容==
==标记样式=={.important|danger|warning|info|tip}
```

用两个`!!`进行包裹

``` md

这是一个注释框
:::

::: info

:::

::: tip
这是一个提示框
:::

::: warning
这是一个警告框
:::

::: caution
这是一个危险警告框
:::

::: details
这是一个详情折叠框
:::
```
