# 说明

整合包基本机制、小特性介绍，大部分内容与游戏任务中相同，建议认真阅读游戏中的游玩前须知，本包对mod内容做了改动，与常规Tetra包略有不同。

## 阶段性

锻造之旅为阶段式流程，且<span style="color:red;background-color:blanchedalmond">锁阶段</span>，未达成阶段要求前无法使用或进入下一阶段的物品或维度。  
请时刻注意屏幕内左下角的文字提示：<span style="color:chocolate;background-color:antiquewhite">二阶段才能进入该维度</span>
::: warning
 一阶段内无法使用锻造锤，进入其他维度传送门会被强制退回主世界
:::

::: warning
一阶段请不要跳进末地传送门，会卡在传送门内，导致反复在主世界与末地间传送。
:::

## 特性

**副手存在物品时伤害减少**，主手和副手同时存在Tetra模组的物品时伤害会减少40%。  
<span style="color:blue">Tetra盾牌除外</span>。

> 原因：
>
>- 主手加成加上加上特定副手武器会导致输出手段过于单调。
>- 为了武器和攻击伤害的多样性，对此部分进行额外限制。

!!其实是主副武器加成多次将作者的预计伤害击碎了!!

## 锻造师等级(**已弃用**)

整合包加入特殊机制“锻造师等级”
锻造师等级分为四级：

- 学徒 | 护甲锻造保留打磨
- 入门 | 锻造的武器带有高质量1，护甲锻造保留打磨
- 精英 | 锻造的武器带有高质量2，护甲锻造保留打磨
- 传奇 | 锻造的武器带有高质量3，护甲锻造保留打磨

**高质量：每级+5%攻击力，+1挖掘效率。**  

**升级方式：**

- 每次使用加工台锻造有10%概率+1锻造经验
- 满10点锻造经验可进入下一等级

## 创造飞行

除了包内提供的几种飞行方式，其它自行添加的mod所提供的飞行方式无法生效。

## 怪物

**一阶段：**

- 主世界普通怪物血量 x2
- 精英怪血量 x5
- BOSS血量 x10
- 灾变boss进行限伤

**二阶段：**

- 怪物血量 x10
- BOSS血量微调约 x20
- 怪物伤害微调约 x4

**三阶段：**

- 怪物血量 +1k
- BOSS血量 +1w
- 护甲 +80
- 怪物每秒恢复360血
- 末地生物伤害额外增加 1.5

## 关于如何前往下一阶段

- 一阶段完成“灾变之心”任务后，后续7个BOSS击杀4个即可进入二阶段
- 二阶段完成帕斯特之梦中风之旅途维度或灯影之下维度其一获得“通行证”即可进入三阶段
