### 描述

>作为食物

- 对剑刃喂： +1HP 上限
- 可用槽位：血肉材料做的剑刃的喂食改进可以喂养活体剑刃，提供一点生命上限加成

::: note 效果

- 幽灵之箭
:::

### 描述

>作为食物

- 幽灵之箭：每次攻击在目标头上召唤幽灵之箭

## [紫水晶蟹肉三明治]

### 效果

::: note 效果

- 长臂
- 延伸
:::

### 描述

>作为食物

- 长臂：增加长臂属性
- 延伸：目标越远，攻击伤害越高。距离目标 3 方块时获得 +8.79% 的加成。
