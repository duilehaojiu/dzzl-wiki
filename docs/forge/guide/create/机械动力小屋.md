## 启动小屋

机械动力模组中的能源名为“应力”，通俗理解为“旋转力”，用旋转来驱动方块工作。对应着现实中的蒸汽机，小屋使用蒸汽锅炉提供应力，但小屋缺少引擎，需要我们手动放置。

1. 首先，我们先找到锅炉的位置

锅炉整体贯穿一层与二层，我们需要在二层放置蒸汽引擎。

![](../image/017.webp)

> 一层图片

![](../image/018.webp)

> 二层图片

![](../image/019.webp)

> 二层全局

2. 领取引擎

引擎的任务点就在领取机械动力小屋的任务点上方，点击对勾后即可领取。

![](../image/020.webp)

3. 安装引擎

在锅炉侧面（如图所示），寻找9个位置摆放引擎，前三个放置之后不会工作，显示“应力过载”，没有影响，第四个引擎则开始工作，放满9个引擎，锅炉的工作效率会更高。

![](../image/021.webp)

![](../image/022.webp)

> 图中引擎的位置可以变化，每个引擎的应力为16384，锅炉最大应力可提供294912，即为18个引擎，可以将该侧全部放满引擎，即可提供最大29万应力。

佩戴工程师护目镜后，准星对准应力表，即可查看剩余应力，如果应力不足，添加引擎即可，29万应力在没有附属模组的情况下，可以说是毕业级别的应力了。

![](../image/023.webp)

![](../image/024.webp)

![](../image/025.webp)

![](../image/026.webp)

4. 确认转向

小屋开始转动后，来到一楼观察粒子飘动的方向，图中转向为正确转向。

![](../image/027.webp)

如果风向相反，请前往二楼应力表下方，与风车轴承相同，准星对准后长按右键调出操作菜单，把转向调至另一侧即可。速度保持256。

![](../image/028.webp)

![](../image/029.webp)

至此，小屋即启动完成，可以进行流水线的加工操作。

## 认识加工流水线

启动小屋后，小屋中的流水线便可以加工物品，这里向没有接触过机械动力的玩家介绍这些流水线的使用方法，其实很好理解，相信使用机械动力的生产方式肯定可以提高处理物品的效率，而不是一味手操。

### 1. 鼓风机流水线

1.1 介绍：鼓风机流水线是机械动力中替代原版烟熏、熔炼的流水线，此外机械动力还新添了两种处理方式：缠魂与洗涤。图中可以看到四个物品展示框，分别为水桶、营火、灵魂营火、熔岩桶，这四种媒介分别对应着：洗涤、烟熏、缠魂、熔炼。

![](../image/030.webp)

::: card title="鼓风机的前置处理"

由于水源方块无法被胶囊打印，作者在一楼的图片位置准备了两桶水，玩家将水右键至树叶中即可：

![](../image/031.webp)

:::

1.2 所有处理方式的使用均为：关闭背包的磁铁功能，把原料悉数放入箱子中，等待片刻，产物会在地板中镶嵌的木桶中出现。（能够被二次熔炼的圆石丢入后会产出平滑石头）

![](../image/032.webp)

1.3 针对可二次熔炼的材料：如需用到大量石头!!这个包应该就这一种可二次熔炼的物品，吧？ !! ，需要更改过滤器。
1.3.1 来到一层，找到烈焰人燃烧室，看到右侧黄铜漏斗上的白布（名为属性过滤器），空手（必须空手）右键即可取下。

![](../image/033.webp)

1.3.2 制作列表过滤器，打开JEI界面后，在非作弊状态下，左键按住石头拖动至列表过滤器中，并点击白名单。

![](../image/034.webp)

![](../image/035.webp)

![](../image/036.webp)

1.3.3 手持列表过滤器，右键黄铜漏斗上的框即可。此时黄铜漏斗在圆石熔炼成石头后，会直接吸入木桶。属性过滤器要保留，在熔炼完石头后放回，避免加工其他物品时失效。

### 2. 序列组装

2.1 介绍：序列组装，可以理解为需要多次加工操作的流水线，使用到的方块一般包括——机械手（安装）、冲压机（冲压）、动力锯（切割）、注液器（注液）。

2.2 构件介绍

![](../image/037.webp)

![](../image/038.webp)

其中各种抽屉、存储控制器、链接工具属于Functionalstorage模组中的物品。

2.3 链接工具使用：
空手右键取出置物台上的链接工具，先右键存储控制器，出现一个绿色的区域，然后右键放置了告示牌的2*2抽屉。

![](../image/039.webp)

![](../image/040.webp)

![](../image/041.webp)

配置完成后，存储控制器和抽屉处均会出现一个白框，如下图。

![](../image/042.webp)

关闭漏斗处的拉杆，流水线便可以实现多次循环的功能。

2.3 案例展示

这里以重型剑刃作为案例。

我们看到重型剑刃的序列组装配方，意思是：首先切割，然后进行三次机械手安装，再进行冲压，循环两次，机械手安装使用的材料（有先后顺序）是精金、精铁、坚固板。

![](../image/043.webp)

我们根据配方的指示，将三种材料放置在三个机械手上方的箱子中（手持材料右键箱子正面，其他侧面右键会调出抽屉的UI界面）

![](../image/044.webp)

并拉动拉杆使其变为关闭状态（未充能的机械手才会工作），不要打开额外的机械手，否则物品会卡在传送带上。

![](../image/045.webp)

检查黄铜漏斗上的过滤器，是否包含“重型剑刃”

![](../image/046.webp)

将原料右键放入2* 2抽屉的任意一格

![](../image/047.webp)

流水线即开始工作，如果机械手上的材料用光，材料也不会进行下一步安装，只需要补充原料即可。

加工完毕的成品会在传送带上飞出，注意拾取掉落物。

![](../image/048.webp)

序列组装对于小白来说是这个机械动力小屋中最容易不会使用的装置了，相信看完这段文章，一定能够熟练使用流水线。

### 3.动力合成器

3.1 介绍：动力合成器其实就是一个更大的工作台，最大5* 5，不会有比这个更大的合成配方（除非作者魔改）。
	
3.2 使用：

3.2.1 更改拉杆位置

作者把拉杆直接放置在了动力合成器的面板上，如果不占用该行格子则不影响，但建议把拉杆转移到图中位置，更方便。

![](../image/049.webp)

3.2.2 填充配方：按照相对位置，摆放配方。

![](../image/050.webp)

3.2.3 拉动拉杆（脉冲即可，甚至你可以换成按钮，拉杆拉完后再拉回），动力合成器开始合成。产物在底部中间的木桶中。

### 4.其他小型装置

4.1 动力搅拌器旁边的加工装置
产物会自动漏出，但这种设计方式存在缺陷，当置物台上存在一个产物的时候，工作盆内不会进行下一项加工，这里建议把置物台打掉，最后加工完成后直接空手右键工作盆即可。

![](../image/051.webp)

4.2 一层加工装置
冲压机一般用来压制铁板、金板等，机械手一般上面放安山合金，置物台上放去皮原木，快速合成安山机壳。

![](../image/052.webp)

### 5.Refinedstorage精妙存储

5.1 使用RS模组中的扳手来对终端进行转向调整。

![](../image/053.webp)

5.2 将一侧的无线发送器（一个小蓝棒棒，在旁边的物品展示框中）插在6格中的任意一格，并放置一个区块加载器（本整合包中的区块加载器是有玩家区别的，如果你是多人联机，你需要放置一个你自己的区块加载器，朋友放置的对你不生效），右键小棒棒打开GUI界面，将维度卡放置在右侧的空白处即可。

![](../image/054.webp)

![](../image/055.webp)

5.3 次元磁铁升级使用：
对准创造控制器shift+右键即可绑定网络，在使用某些机械动力流水线的时候，一定要注意关闭磁铁升级，很有可能出现东西放下后找不到去哪了的情况。
