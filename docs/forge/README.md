# 简介

锻造之旅是一款以Tetra为核心的国产冒险整合包，拥有大量自制饰品，大量可锻造材料，独具特色的盔甲锻造、天雷锻兵、血肉盔甲、机械盔甲等。
本整合包包含机械动力，但机械动力并不是游戏流程中必须的一部分，贴心为普通玩家设置机械动力预制小屋，可以满足本包基本的机械动力需求。
