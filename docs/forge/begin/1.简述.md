整合包的基本机制与特性介绍，该部分多数内容均与游戏任务书中的介绍相同。新手游玩建议认真阅读任务书中的**游玩须知**部分。

锻造之旅是以Tetra为核心的冒险整合包，拥有各具特色的**模块化武器**，**模块化的盔甲、饰品**，以及大量带有各种效果的**Tetra材料**，玩家可以发挥创造力打造独一无二属于自己的装备。

::: info 整合包对部分mod内容进行了改动，与其它Tetra包略有不同。
:::

## 阶段性

锻造之旅为==阶段式流程=={.important}，玩家可获取资源的强度与自由度随阶段发展。**推进任务流程**并击败特定boss即可在任务书中解锁下一阶段。

::: warning 一阶段内无法使用锻造锤，进入其他维度传送门会被强制退回主世界
:::

::: timeline

- ==阶段一==
  - 只能探索主世界
  - 工具最高等级：锤 5级，斧 5级，撬 5级，切削 5级；对应只能使用一阶段材料

- ==阶段二==
  - 新增可探索下界、染梦世界、深暗之园、风之旅途、灯影之下、洞穴维度；
  - 工具最高等级：锤 8级，斧 7级，撬 7级，切削 6级，可以使用锻造锤；对应可使用二阶段及之前的材料

- ==阶段三==
  - 新增可探索末地、二轮世界
  - 工具最高等级：锤 9级，斧 9级，撬 9级，切削 7级；可以使用整合包中所有Tetra材料

- ==阶段四==
    time=开发中 line=dashed
  - !!还在开发中(～￣▽￣)～!!
:::

一阶段推进任务，击败boss**咒翼灵骸**后在任务书奖励中进入阶段二。  
二阶段推进任务，在下界击败boss**焰魔**、探索染梦世界并进入**风之旅途或灯影之下**维度探索、在深暗之园击败**遗忆守卫**、在洞穴维度击败**窥心者**、**遗弃者**与**磁控机兵**后即可在任务书中进入阶段三。

## 多流派

整合包中有多种不同**流派**，如火焰、瘟疫、辐射、激光、唤雷、长弓、幸运横扫等。每种流派通常基于特定的伤害机制。各有一系列材料对某种流派有特殊加成。
::: note 流派并非完全固定，没有固定的毕业武器！
:::
玩家对流派的选择较为自由，只需锻造合适的武器、制作一些装备就可以体验，各种流派组合也更方便了战斗与探索。另外，各个流派之间**并非互不相容**，发挥想象力融合不同流派的材料搭配也许会有意想不到的效果。也有部分材料对各类伤害都有加成，鼓励玩家多多尝试不同的配装。!!神器模板不可取!!

对于不熟悉各种材料特性的新手，任务书中准备了各阶段部分流派的**参考配置**，新手玩家可以以此为起点学习各种搭配。
>我们鼓励玩家自行探索尝试不同材料的搭配锻造，寻求独属于自己的独特武器，而不是完全照搬已有的作业

## 怪物

::: note 由于Tetra多种多样的模块与改进使武器数值远超原版，为了维持游戏的相对平衡性整合包对应强化了所有的怪物。
:::

::: timeline

- 一阶段
  type=danger
  - 普通怪物血量×2，自带约5护甲值
  - Boss血量修改，约1000~6000，自带约50护甲值
  - 一阶段额外Boss（难度极高，不在主要流程中，可选择跳过）血量约20000，自带约60~80护甲值，另有减伤特性

- 二阶段
  type=danger
  - 普通怪物血量+400，自带约30护甲值
  - Boss血量修改，约10000~30000，护甲值各不相同
  - 二阶段额外Boss（难度极高，不在主要流程中，可选择跳过）血量约50000，自带约100护甲值，部分另有减伤、无敌帧等特性

- 三阶段
  type=danger
  - 普通怪物血量+1000，自带约40护甲值
  - Boss血量修改，约30000~80000，自带约100护甲值

- 永恒竞技场
  type=danger
  - 通关阶段三及之前的所有流程后解锁，难度逐渐升高
  - Boss血量逐渐升高，50波后达到数十万不等，自带护甲值数千，攻击伤害极高 ~~（脚填数值）~~  

此外，怪物及Boss攻击伤害均有调整；原带有免疫负面状态、限伤、特殊独立无敌帧、吸血等特殊能力的Boss有一部分被移除了这些能力。
