### 简介

一个为 Minecraft 游戏打造的模组扩展包，专注于新增材料、Boss、战斗机制与平衡性调整，为玩家带来更丰富的游戏体验与挑战。

### 使用方法

将压缩包内的 `kubejs`、`config`、`mods` 文件夹与游戏文件夹下的同名文件进行覆盖即可。

### 开发者说明

- 本项目托管于 Gitee：[TheophanyDLC](https://gitee.com/lingmu0/TheophanyDLC)
- 如无特别说明，“普攻”、“平A”特指近战攻击伤害。

### 其他说明

- 后续末地dlc将合并至本dlc并进行兼容更新

## 铁魔法非官方DLC

- 下载：锻造之旅官方群内提供下载

### 介绍

- 锻造之旅-铁魔法非官方dlc
- 添加了全新的流派、材料、武器类型

### 安装说明

:::: steps

1. 适配版本为整合包1.2或者1.1.2
    ::: warning
    安装前请确认整合包版本！
    :::

2. **安装dlc本体前，请确认整合包版本**
    - 1.2直接安装
    - 如果你的整合包版本是1.1.2，请先安装“额外适配”文件夹内的mod，并将原整合包kubejs/server_scripts内文件替换为压缩包内文件
    ::: info
    - 压缩包内文件、代码来自整合包本身，是整合包原代码修改过后得到。因为本dlc目前直接适配的1.2，故为了在1.1.2使用本dlc，需要对整合包部分原代码进行调整
    - 也因为这个原因，目前本dlc在1.1.2版本暂时不兼容其他dlc
    :::
3. 剩余文件直接拖入游戏文件内即可
::::
