# 锻造之旅百科项目

网站使用 [vuepress](https://vuepress.vuejs.org/) 和 [vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume) 构建生成。

目前项目处于停滞阶段有兴趣的朋友可以续接项目

~~说不定哪天我又想继续做了😋~~

## 说明

- 项目使用vuepress的plume主题进行构建
- 项目所有内容以markdown书写并通过vuepress渲染为网页
- 具体的构建调试和语法请参考[vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume)提供的文档
- 由于间隔时间较长clone到本地后请按照plume文档更新主题并查看配置文件开启了哪些插件
- 本人自定义了部分css样式，如续接请查看项目中的自定义css文件

由于作者经常更新整合包调整数值，采用静态网页对于更新和发布其实都不是很理想

项目也使用静态网页CMS：Decap CMS，且进行了部分配置用于在**锻造心得**部分发布内容，事实上它并不好用所以我已经在配置里关闭它了(我记得是关闭了)

所有已经做好的内容和计划做的内容文档均在**QQ群：1094131350**

关于本项目的内容也可以咨询群主如果我还记得当时是怎么做的🤔
